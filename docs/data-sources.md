# Data Sources

Supported ingestion modes:
- Public API connectors
- ArcGIS FeatureServer connectors
- CSV and Excel imports
- Public HTML portals
- Manual administrative uploads
- Right-to-Know response uploads

Rules:
- Never bypass authentication, CAPTCHA, robots restrictions, terms of service, or access controls
- Keep source provenance for every imported record
- Retain the original source description even after normalization
- Use Right-to-Know workflows when no public machine-readable source exists
